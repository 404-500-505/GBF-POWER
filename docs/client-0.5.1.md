# 客户端 0.5.1：自绘交互控件

本次仅更新 Windows 客户端，不修改管理端、服务端、路由、授权或缓存策略。

- 按钮统一圆角，增加约 140 ms 的悬停、按压过渡与键盘焦点提示。
- 开关、复选框、单选框使用自绘图形，不再依赖默认控件换色。当前客户端中的启用缓存与窗口置顶使用开关。
- 线路、外观下拉及更多菜单使用自绘圆角弹层，支持方向键、回车、空格、Esc、Tab 和点击外部关闭。
- 同一状态重复上报不触发动效；控件销毁会释放定时器、变量监听与弹层抓取。
- 浅色、深色、跟随系统继续可用；切换主题不会重建代理会话。
- 弹层依据所在显示器工作区定位，避开任务栏；多屏坐标计算有单元测试，仍需在真实多屏环境复验。

这些是 Tk/Pillow 绘制的兼容型玻璃风格控件，不是 macOS Liquid Glass 或 Windows 桌面实时背景模糊。当前没有新增屏幕阅读器 UI Automation 桥接；键盘支持不等于完整无障碍认证。

## 验证

`client/windows/tests/test_client_controls.py` 覆盖鼠标按压取消、禁用、变量语义、键盘提交/取消、弹层关闭与销毁、主题切换、重复状态更新与多屏定位计算。运行公开客户端测试：

```powershell
python -m unittest discover -s client/windows/tests -v
```

从旧版本更新时先停止加速并退出客户端，再运行安装包。此版本没有用户配置或缓存迁移。
