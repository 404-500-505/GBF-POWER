# Windows 客户端 0.5.0

本次仅更新 Windows 客户端及内置素材网关统计，不修改管理端或服务端。

## 外观

在窗口顶部选择「浅色」「深色」或「跟随系统」。选择保存在本机 `desktop.json`，重启后恢复；切换主题不会断开代理。跟随系统模式约每 2 秒检查一次 Windows 应用颜色设置。

采用 Apple 风格的磨砂圆角卡片、细边框与阴影。为兼容现有 Tk 客户端，内容层保持不透明，不捕获桌面背景、不使用全窗口透明度，也不宣称实现 macOS 原生 Liquid Glass。Windows 原生标题栏按系统能力适配，不支持时保留原样。

屏幕较小时可滚动查看卡片，启停操作与 PAC 提示始终保留在底部。主题仅影响客户端，不影响独立管理端。

## 连接体验

- 分开显示启动、授权确认、本地代理就绪、加速通道就绪和停止状态。
- 普通与已启用的战斗通道均就绪后才显示可用；网络探测成功不代表战斗请求成功。
- 节点 TCP 探测最多三个并行，避免一个失联节点串行拖延其他结果。该探测不是完整 SSH 握手，也不是游戏丢包率。
- 显示的延迟绑定当前代理会话的真实出口；重启或出口变化后重置样本，忽略迟到的旧探测结果。
- 证书状态通常每 30 秒扫描一次，客户端完成证书操作后刷新；授权检查和五分钟失联停用规则不变。

## 缓存统计

| 字段 | 口径 |
|---|---|
| 素材请求 | 本会话通过本地校验并进入素材处理的请求，包含回源失败 |
| 直接命中 | 本地素材直接返回，无需回源校验 |
| 校验复用 | 源站确认有效后复用本地内容，与直接命中分开计数 |
| 网络下载 | 网关完整接收的成功、有正文的 GET 响应数量，不含 304、错误或截断响应 |
| 节省传输 | 从本地复用的素材正文大小，不包含回源校验的协议开销 |

这些不是浏览器或游戏的全部流量。旧版引擎缺少相应计数时显示「—」，不猜测为零。本次没有放宽版本资源、旧 ACGP 素材、响应头或源站证书的校验要求。

## 升级与边界

先停止并退出旧版，再覆盖安装。保留 `%LOCALAPPDATA%\GBFDesktop` 中原有设备凭据、缓存与用户配置；不需要因主题更新重新激活。

本次不包含国内中继、远程共享缓存、连接级动态出口选择或 Steam/UDP 加速；这些需要独立设计与验证。服务器白名单和登录、战斗流量的加密透传边界保持不变。

仅供学习交流，请遵守所在地法律法规，不得用于非法搭建或使用 VPN 等活动。
