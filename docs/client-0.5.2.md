# 客户端 0.5.2：紧凑窗口与弹层层级修复

本次仅修复 Windows 客户端界面，不修改管理端、服务端、线路、授权或缓存逻辑。

- 默认窗口由约 520×967 收紧为约 480×760，统计内容在内部滚动，启停操作仍固定在底部。
- 删除窗口几何对 Tk DPI 比例的重复放大。150% 字体缩放测试中，窗口由约 780×967 降至约 627×760，并保留内容的最小宽度。
- 自绘下拉框及更多菜单在完成映射后明确提升到主窗口之上，修复主窗口开启「窗口置顶」时弹层被遮住的问题。
- 保留点击外部关闭、Esc、方向键、回车、Tab、主题切换、多屏工作区定位及弹层销毁清理。

新增回归测试会检查默认/高 DPI 窗口尺寸，以及 Windows 实际 Z 顺序中弹层位于置顶主窗口上方。
