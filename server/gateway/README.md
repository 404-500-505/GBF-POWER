# 网关服务

网关与控制端共用 `server/control` 下的同一个 Go 模块和可执行文件。构建后用以下子命令启动独立网关：

```text
gbf-activation gateway --config FILE
```

先复制并填写本目录的 `config.example.json` 和 `rules.example.json`。`${...}` 是部署时必须替换的占位符，不能原样启动。配置校验采用失败关闭策略：监听地址、SSH 用户名、绝对密钥路径、绝对规则路径、节点身份、HTTPS 控制端地址和 64 位十六进制证书摘要缺一不可。

网关只转发规则文件明确允许的目标。请为每个节点生成独立的 Ed25519 主机密钥和节点身份密钥，限制文件权限，并仅开放部署所需端口。不要把私钥、真实地址、证书摘要或运行状态提交到仓库。

本项目仅供学习、研究与技术交流。请勿未经许可搭建或经营 VPN、公共代理或绕过访问控制，并遵守所在地法律法规和相关服务条款。
